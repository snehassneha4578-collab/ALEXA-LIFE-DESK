## 💻 Run Locally

1. Clone the repository:

   `git clone https://github.com/snehassneha4578-collab/ALEXA-LIFE-DESK.git`

2. Open the project directory:

   `cd ALEXA-LIFE-DESK`

3. Install dependencies:

   `npm.cmd install`

4. Configure local environment variables using `.env.example`. Keep API keys and credentials private.

5. Start the application using the available scripts in `package.json`.
