## 🌈 Welcome to ALEXA LIFE DESK

ALEXA LIFE DESK is an AI-powered personal productivity workspace designed to bring everyday planning, focus, and productivity tools together.

![ALEXA LIFE DESK Cover](public/images/life-desk-cover.png)

## ✨ Features

| Feature | What it does |
|---|---|
| 📝 Task Management | Organize tasks and daily priorities |
| 🎯 Focus Room | Run focused work sessions with a timer |
| 📊 Productivity Insights | Review productivity information |
| ⚙️ Settings | Manage available workspace preferences |
| 💾 Local Persistence | Save supported task data using browser `localStorage` |
| 🤖 AI Assistant | Integrate with Amazon Bedrock when configured |

## 💻 Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/snehassneha4578-collab/ALEXA-LIFE-DESK.git
cd ALEXA-LIFE-DESK
```

**2. Install dependencies**

```bash
npm install
```

**3. Configure environment variables**

Use `.env.example` as a reference. Keep API keys and credentials private. Never commit your `.env` file.

**4. Start the application**

Follow the available scripts in `package.json` to start the frontend and backend.
