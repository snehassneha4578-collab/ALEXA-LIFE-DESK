## Technology
- React and Vite
- Node.js and Express
- Amazon Bedrock integration when configured
- Browser localStorage

## Run Locally
Install dependencies:
`npm.cmd install`

Start the frontend:
`npm.cmd run dev`

Start the backend in a separate terminal:
`npm.cmd run server`

Backend health check: `http://127.0.0.1:8787/api/health`

## Checks
`npm.cmd run build`
`npm.cmd run lint`

## Security
Keep API keys and `.env` files private. Never commit credentials.
